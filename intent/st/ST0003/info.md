# ST0003: Post-port simplifications, then 2.0.1 by one command

## Objective

Make pplr simpler without changing what it does, from the candidates that critic-rust's second read of ST0001 WP11 commit 3 (fe4b677) left on vc's board, under hv's rule that a change now makes pplr simpler or easier and adds nothing (vc decision 2). Then release the result as pplr 2.0.1 with one command, `bin/devbin release v2.0.1`, the first real run of its `after:`, `bin/devbin post-cut` (vc decision 27).

## Context

hv, 2026-11-04: vc has the pen on pplr, cldr and ccusage. All three are to be properly finished this morning, each releasing signed and notarised by one devbin command. pplr's part is this thread. pplr-dc implements it and vc reviews it.

The candidates. Each one preserves behaviour unless it says otherwise:

- `Pair.how` (src/sync.rs) is a `&'static str` over five words: linked, email, linkedin, phone and name. An enum names them once, and the JSON and the report print the same words.
- `Pair.has_inetloc`: `check()` reads it and `matches()` leaves it false, so false means both "absent" and "not read". "Not read" becomes a state of its own.
- `workbook::write` fills Merged's rows by position, while the reader and the styling go by header. It fills them by header too.
- One macOS gate: contacts/mod.rs, handler.rs and icons.rs each test `cfg!(target_os = "macos")` with their own message, beside open.rs's `macos_only(why)`. One helper serves every gate, and every message stays as it is.
- One walker: grep.rs, links.rs and rename.rs each recurse on their own, with different rules for order, dot names and symlinks, each matching the legacy tool it replaced. They share one walk only if it keeps every rule and reads simpler. Otherwise the package records why and is cancelled.
- One picture rule, a divergence that needs hv's ruling: `tree::PICTURES` takes the first file in About/ by name with any picture ending, while `pplr pictures` and the index try the extensions in turn, so a folder with two pictures can give a different one to each. On the live tree on 2026-11-04, none of the 358 About folders with a picture holds two, so unifying the rules changes no output there today.
- The walks pass over a directory they cannot read without a word, where the legacy's `grep -r` and `find` named it on stderr. Saying so is a divergence, and hv's ruling.
