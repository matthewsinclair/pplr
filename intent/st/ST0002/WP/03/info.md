# WP-03: Install, manifest, tree identity, version line and use

## Objective

Give the binary the dev/opt/brew verbs, with their doctor rows: `install`, the manifest, the tree function, the version line and `use`.

**Scope**

- **T2**: `pplr install [--prefix <dir>] [--force] [--managed-by brew]`.
  - It publishes only from a dev tree, and refuses a dirty runtime set.
  - It replaces a prefix only with `--force`, and only when the manifest says pplr wrote that prefix.
- **T3**: the manifest at `<root>/.pplr-install`. Its header carries `tool`, `version`, `source_commit` and `managed_by`. Its body has one `shasum -a 256 -c` line per runtime file, sorted with `LC_ALL=C`.
- **T4**: one function names the tree. The version line is `pplr <version> (<tree>, <sha12>[+dirty])`, built from stamps taken at build time:
  - the commit;
  - dirtiness, measured over cargo's dep-info plus the sidecar source;
  - an optional provenance word.
- **T5**: `pplr use [dev|opt|brew]`.
  - The link set is `pplr` alone, in `~/.local/bin`.
  - It refuses a missing tree, and refuses `use brew` when no brew copy would answer.
  - It runs the shadow check.
- **Doctor rows** for the tree, manifest drift and the shadow check. These are added to ST0001 WP12's doctor.
- **Tests** go in `tests/cli.rs`, using the `Sandbox` with HOME and PATH redirected and a fake brew prefix.

**Criteria**: AC-03.1 to AC-03.3.

**Depends on**: ST0001 WP02 and this thread's WP01.
