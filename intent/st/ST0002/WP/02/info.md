# WP-02: devbin release core and CI candidates

## Objective

Configure devbin's release core and formula tool for pplr, and make CI fire on release candidates.

**Scope**

- **`bin/.devbin/config.yaml`**:
  - `version_from: Cargo.toml`;
  - `commands.release.enabled` and `commands.formula.enabled`;
  - a `release:` block naming the repo, the remotes (local then upstream), the gates (`check all`, `test all`, `doctor`), the kovacs leg, `derived: [tools/lock-sync]` and `after: [bin/devbin formula publish]`;
  - `formula: mode: assets` (E1, as ruled).
- **`tools/lock-sync`**, in zsh after Gtools' model: rewrite `Cargo.lock` for the new version, then print `Cargo.lock`.
- **CI**: `tests.yml` fires on `main` and on `candidate/**`.
- **CHANGELOG**:
  - opens `## [2.0.0] - unreleased`;
  - merges the duplicate `### Fixed`;
  - keeps the history of 1.0.1 and earlier.
- `bin/devbin release check` and `bin/devbin doctor` pass.

**Criteria**: AC-02.1 and AC-02.2.

**Depends on**: ST0001 WP02, which brings the crate, devbin's gates and `tests.yml`.
