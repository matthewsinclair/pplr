# ST0002: Create a homebrew distro for the new Rust version of Pplr

## Objective

Make Homebrew the way Pplr reaches a machine. `brew install matthewsinclair/pplr/pplr` installs a source-built formula, rendered by devbin's formula tool into the tap `matthewsinclair/homebrew-pplr`. Releases are cut by devbin 0.1.19's release core, with gates run locally, on the kovacs leg and in CI. pplr follows devbin's dev/opt/brew contract (T1 to T10). The thread ends with rhadamanth running brew's pplr at 2.0.0.

## Context

**Why.** Pplr runs today from a checkout, through a `~/.local/bin/pplr` symlink into `bin/`, with a Swift engine compiled at run time and Python run under `uv`. ST0001 replaces all of that with one Rust binary and a Swift Contacts sidecar built ahead of time. This thread ships that binary the way the user's other tools ship.

**The contract.** devbin's `docs/dev-opt-brew.md` (T1 to T10): three trees (dev, opt, brew), a manifest, one version line, `pplr use dev|opt|brew`, and a formula rendered from a template and never typed. Molt, Utilz, Intent and devbin follow it, and devbin's release flow expects it. dc proposed it.

**Precedent** (the attached `design.md` has the detail):

- Cldr renders a source-build formula into its own tap.
- Ccusage ships Developer ID signed tarballs, for Keychain access, through Python tooling.
- devbin 0.1.19's release core and `formula: mode: source` cover what Pplr needs without either project's bespoke tools.
- hv created `matthewsinclair/homebrew-pplr` on 2026-11-02. It is empty, and its description still names cldr.

**Decisions** E1 to E8 are in the attached `design.md`, revised with hv's rulings of 2026-11-02:

- an `assets` formula installing signed release builds, after Intent's;
- every macOS binary signed and notarised with hv's Geodica Developer ID, by a bash or zsh signer ported from Intent's;
- devbin's release core, with remotes local then upstream, the kovacs leg and CI on `candidate/<tag>`;
- the version in `Cargo.toml`, and `Cargo.lock` kept by a zsh `derived:` step;
- the existing tap, `matthewsinclair/homebrew-pplr`, with its description corrected and its own CI;
- dc runs the cut, with hv's approval of each outward step.

**Depends on ST0001.** WP02 to WP05 here build on ST0001's scaffold (ST0001 WP02). The release (WP06) waits for ST0001's cutover (WP13).
