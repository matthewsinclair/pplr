# WP-04: Core model and the read commands

## Objective

Build the core every command shares (the tree, person references, the About header, normalisation and markers), and port the commands that only read.

**Scope**

- **Modules** `tree`, `about`, `normalise` and `marker` (design 3.1), as pure functions with unit tests taken from the Swift and bash behaviour:
  - the walk rules;
  - `PersonRef`, which accepts two arguments, `Surname, First`, `L/Surname, First` or a `pplr://` marker;
  - the header fields as the engine reads them;
  - case and diacritic folding matching Swift's on the fixtures, phones, Gmail keys and LinkedIn slugs;
  - the marker path and URL, aliases, and `pplr://tag/<t>`.
- **Native commands**: `resolve`, `count`, `about`, `cp`, `open`, `linkedin`, `edit`, `meetings`, `refresh`, `grep`, `help` and `version`.
  - `open` percent-encodes without `python3`, and probes the CMS without `curl` if that stays simple.
  - The version tests are re-pointed at `Cargo.toml`.
- **Deletion**: rewire any legacy caller first (eg `pplr_open` calls `pplr cp`), then delete these commands' bash.
- **Errors** go to stderr (D10).

**Criteria**: AC-04.1.
