# WP-08: Rename, links and the pplr:// handler

## Objective

Port rename, link rewriting and the `pplr://` handler.

**Scope**

- **`rename`**:
  - every path form, replaced in one longest-first pass per file;
  - the include and exclude lists;
  - refs directories reached through symlinks;
  - the person's own files and About text, and `.index/aliases`;
  - the list of prose mentions, then a reindex;
  - `--dry-run` changes nothing.
- **`links`**: the engine's conversion. Each real file is rewritten once, with symlinks followed and kept. Paths are relative to the caller's directory. It takes `--apply` and `--json`.
- **`handler --install|--uninstall|--status`**: the app runs the stable path of the running tree. Under brew that is the opt link, never a Cellar path (ST0002); in dev it is the checkout's build. The `PATH` the app sets no longer needs `swiftc` or `python3`.
- Delete `pplr_rename`, `pplr_links` and `pplr_handler`, and the sidecar source's `resolve`, `links` and `people` modes.
