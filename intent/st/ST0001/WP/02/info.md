# WP-02: Rust scaffold under devbin, with the fallback

## Objective

Stand up the Rust crate in house style, with devbin's gates and CI on macOS and Linux. Build a `pplr` binary that runs every command, natively once ported and through the fallback until then, so the whole bats suite passes against it from this WP on.

**Scope**

- **The crate** (design D5 and 3.1):
  - `Cargo.toml` at the root: package `pplr`, version 2.0.0, edition 2024, `rust-version`. rhadamanth has Homebrew's Rust and no rustup, so there is no `rust-toolchain.toml`. `[lints]` sets `unsafe_code = "forbid"` and denies `unwrap_used` and `expect_used`.
  - `rustfmt.toml` with `edition = "2024"` and `tab_spaces = 2`.
  - A thin `src/main.rs`, plus `src/lib.rs`, `src/cli.rs` (the command table, the argument helpers, help generated from the table), `src/error.rs`, and `src/config.rs` (the data root per D8, the XDG defaults per D5).
  - `tests/cli.rs` with a `Sandbox`, after Ccusage's.
- **The fallback** (design 3.3). This WP ports no command: every command, `version` and `help` included, runs through the fallback until its own WP.
- **devbin**:
  - Make the vendored devbin 0.1.19 (`bin/devbin`, `bin/.devbin/`) ready to commit, with its config declaring `rust`, and `shell` for the suite.
  - `check all` and `test all` run the cargo gates (fmt, clippy with the house lints, test, autotests, targetdir) and the bats suite against the Rust binary, through WP01's seam.
- **Hygiene**: rewrite `.gitignore` for Rust and Swift (`target/`, `tmp/`, `.build/`) and drop the Mix entries; fence `bin/.devbin/lib/` in `.prettierignore`; remove the tracked Finder `Icon\r`.
- **CI**: `.github/workflows/tests.yml` on macOS and Linux, hardened as in ST0002 E6, running the cargo gates and the bats suite against the Rust binary. Retire `test.yml`. ST0002 WP02 adds the `candidate/**` trigger.
- **The install-layout seam** (design 3.4), agreed with ST0002 WP01: one function returns the binary's resolved root and the sidecar's path beside it.
- **Languages**: with hv's agreement, run `intent lang init rust shell swift` so the critic gate arms.

**Criteria**: AC-02.1 and AC-02.2.

**Heavy runs** go through `intent estate slots`: cargo and bats each have one heavy lane, shared with Devbin and Utilz.

**The People leak check** (D11): a check in the gate, eg `bin/devbin check people-leak` called from the pre-commit hook. It reads the folder names, their `pplr://` markers and the About emails from `PPLR_DATA` at run time and fails on any match in the staged tree. The names are never written into the repo. Skip it with a stated reason when `PPLR_DATA` is absent (eg on CI).

**AGENTS.md**: `intent claude upgrade` generated build and test lines for a SwiftPM package (`swift build`, `swift test`, `Package.swift`), but the sidecar is a single file compiled with `swiftc`. Correct them through Intent's generator, never by hand-editing `AGENTS.md`.
